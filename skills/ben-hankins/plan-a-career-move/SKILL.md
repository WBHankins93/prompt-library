**When to use this skill:** a career option is consequential enough that prestige, fear, or salary
alone would produce a brittle decision.

**What it produces:** weighted criteria, option evidence, transferable-skill and gap maps,
reversible tests, positioning, transition steps, and stop conditions.

## Define the next chapter

Separate the desired work, learning, environment, autonomy, compensation, geography, and life
constraints. Rank them and name tradeoffs. Describe what success should look like in two years, not
only the title acquired next month.

## Evaluate the real options

Include staying and redesigning the current role. For each option, gather evidence about daily work,
manager quality, decision scope, market demand, compensation, failure modes, and reversibility.
Speak with people doing the work and distinguish recruiting narrative from operating reality.

## Map proof and gaps

Translate existing results into the target role's language. Separate missing vocabulary from
missing capability and missing credential. Build proof for the smallest load-bearing gap through a
project, stretch assignment, advisory work, or focused learning.

## Buy information before commitment

Run reversible tests: shadow work, portfolio artifact, targeted conversations, application sample,
or contract engagement. Define what signal increases or decreases fit. Avoid resigning merely to
create urgency when learning can happen while employed.

## Build the transition sequence

Set positioning, target list, relationship strategy, evidence assets, financial runway, dates, and
decision gates. State conditions for accepting, declining, or staying. Reassess when evidence
changes rather than moving the criteria to justify a favored answer.

## What good looks like

The move fits the desired work and life constraints, rests on observed reality, and uses existing
strengths without pretending gaps do not exist. Reversible tests reduce uncertainty, the financial
downside is bounded, and the candidate knows what evidence would make them choose differently.

## Hard rules

- NEVER optimize a career decision for title alone.
- NEVER confuse unfamiliar vocabulary with missing ability.
- NEVER create irreversible urgency when a reversible test is available.
- ALWAYS include staying as a real option.
- ALWAYS define acceptance and walk-away conditions before an offer arrives.
